The twist

Local SMP runs vanilla survival with exactly one house rule, and it changes how the whole server plays.

Dragon Egg twist

Whoever is holding the dragon egg in their inventory, not just nearby, actually carrying it — gets Strength III for as long as they keep it.

This is so that players dont hoard the dragon egg in there Ender chest (therefore making it impossible to get) It's a portable advantage that everyone on the server knows about and everyone wants.

What you're joining

Vanilla-first survival

No item-spawning, no economy plugins that undercut trading. If it isn't in base 1.21.11, it isn't here. Except the egg.

One egg, one server

There's a single Ender Dragon egg in the world. Whoever holds it has the power to kill almost anyone

Small, known community

Whitelist-only. Everyone playing is someone you can actually talk to.

House rules

That's it. Everything else, griefing, PvP, raiding the egg or the mace off someone is fair game.

No killing AFK players. If someone's clearly away from keyboard, leave them alone.

No trapping AFK players. Don't box them in, wall them off, or otherwise mess with them while they're away.

No combat logging. If you're in a fight, you see it through don't log out to dodge a death.
